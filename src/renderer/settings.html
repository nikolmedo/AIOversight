    Webhook recipe
    
      
    
        For agents we don't introspect natively (GitHub Copilot, Gemini /
        Antigravity, Cline, custom MCP servers, shell hooks, CI…), POST a JSON
        payload to the local webhook to fire a notification.
      
    
      
    
      
    Hook examples
    
      
    Add to a Claude Code SessionStart/PreToolUse hook, a Cursor hook, an Aider --read command, or any agent-side script:
    
      
    {
  "agent": "Copilot",
  "sessionId": "vscode-workspace-123",
  "kind": "waiting",
  "title": "Copilot wants to run a command",
  "message": "Allow execution of 'npm install'?",
  "source": "/Users/me/projects/myapp"
}
    
      
    
        kind is "waiting" (default) or "finished".
        Use "finished" from a shell wrapper that traps the agent's exit
        to be notified when its OS process terminates. All fields except
        agent and message are optional.
